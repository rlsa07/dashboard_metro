# Dashboard de Ocorrências Ferroviárias

Pacote pronto para publicação no GitHub Pages.

## Publicação

1. Crie um novo repositório no GitHub.
2. Faça upload de todos os arquivos desta pasta para a raiz do repositório.
3. Vá em **Settings > Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)**.
6. Clique em **Save**.
7. Aguarde a publicação e use o link fornecido pelo GitHub Pages.

O arquivo principal do site é `index.html`.

Observação: o dashboard é autônomo e não depende de arquivos externos.
